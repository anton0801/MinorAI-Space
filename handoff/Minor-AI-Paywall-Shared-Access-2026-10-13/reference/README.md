# Фирменные материалы

DESIGN.md и tokens.* — исходная дизайн-система. При конфликте со старым paywall следовать новым макетам и IMPLEMENTATION.md. Встроенные в DESIGN.md ссылки на исходные компоненты могут требовать полного репозитория; компонентная HTML-галерея в этот компактный пакет не входит.

minor-logo.png — копия реального фирменного знака, не генеративная перерисовка. Полные локальные пути в prompts.json и source-manifest.json сохранены как происхождение; их не нужно воспроизводить на другом компьютере.
