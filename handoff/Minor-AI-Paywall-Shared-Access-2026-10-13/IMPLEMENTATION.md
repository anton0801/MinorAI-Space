# Задание на текущие изменения

## 1. Сначала сверить проект

Точки входа по состоянию на 12 октября: `Minor Ai/Views/PaywallView.swift`, `Minor Ai/Services/SubscriptionStore.swift`, `Minor Ai/MindMap/CollabSheet.swift`, `Minor Ai/Services/CollabService.swift`, миграции совместного доступа в `supabase/migrations/`. Названия и состояние проверить заново. Не заменять чужие незавершённые изменения старым кодом из аудита.

## 2. Paywall

После выбора A/B использовать одну композицию для Plus и PRO. Верх — название/польза; дальше выбор тарифа, короткие преимущества и подробности, два варианта оплаты, основная покупка и служебные действия. Тариф и период независимы. При смене выбора одновременно обновляются продукт, цена, преимущества и CTA; покупка должна относиться к показанному продукту.

Цены из PNG служат только примером. Отображать локализованный полный платёж из StoreKit. Не переносить в код $12.99/$119.99 как запасной вариант при недоступности магазина. Годовая сумма заметнее пересчёта за месяц. Trial показывать только при подтверждённой применимости и вместе с условиями последующего платежа. Уже активный продукт не предлагать купить повторно; сохранить управление подпиской и корректный маршрут смены тарифа.

Преимущества брать из действующих правил: не обещать безлимит, не менять квоты, названия продуктов и доступ к моделям. «Все возможности и лимиты» открывает понятное сравнение. Шевроны у отдельных преимуществ либо ведут к соответствующему объяснению, либо удаляются.

| Состояние | Поведение |
|---|---|
| Загружаются цены | Понятная загрузка; покупка недоступна, закрытие доступно |
| Цены недоступны | Повтор загрузки без фиктивного платежа |
| Покупка выполняется | Защита от повторного запуска; показ выбранного продукта |
| Ожидание подтверждения | Честный статус ожидания, без выдачи платных прав заранее |
| Отмена пользователем | Возврат к выбору без красного сообщения об ошибке |
| Ошибка | Короткое объяснение и повтор, выбор сохранён |
| Успех | Подтверждённые права; возврат к исходному сценарию без двойного выполнения |
| Восстановление | Процесс, успех / ничего не найдено / ошибка; реальное обновление статуса |

«Восстановить покупки», условия и конфиденциальность — доступные действия. Сохранить необходимый полный текст действующего paywall; сокращённая подпись изображения его не заменяет. На малом экране допускается прокрутка, декор сокращается раньше полезной информации. Цена и ссылки не перекрываются свечением или частицами.

## 3. Общий доступ

Кнопка с двумя людьми в заголовке карты открывает приглашение для личной карты или участников для общей. Не смешивать этот вход с экспортом публичного снимка.

**Владелец:** создаёт приглашение с ролью, меняет роль участника, удаляет его, отзывает ссылки, прекращает совместную работу. **Редактор:** редактирует карту. **Наблюдатель:** читает, меняет личный масштаб/фокус, не пишет в общие данные. **Участник:** может выйти. Реальные правила проверяются сервисом/сервером, не только видимостью кнопок.

Создание ссылки — отдельная операция с прогрессом и ошибкой. Системная отправка не означает автоматически, что сообщение отправлено. «Скопировано» показывается после успешного копирования. Открытие панели не добавляет участников. Приложение не должно отправлять приглашение человеку без действия пользователя.

Получатель видит разрешённые метаданные, роль и «Присоединиться / Не сейчас». Если требуется вход, после него восстановить то же приглашение. До получения прав не загружать приватные узлы ради миниатюры — нейтральная иллюстрация вместо содержимого. Повторное присоединение не создаёт новую карту. Получатель не выбирает себе повышенные права.

Смена роли / удаление подтверждаются сервером; при ошибке интерфейс возвращает действующее состояние. Если права отозваны во время редактирования, закрыть изменяющие действия и объяснить ситуацию; отложенный AI-ответ тоже не должен обходить запрет записи. Предел участников берётся из действующего сервиса с согласованным учётом владельца.

Отзыв ссылок препятствует новым присоединениям, но сохраняет участников. Удаление конкретного человека и прекращение общего доступа — отдельные действия с пояснениями. Не обещать уничтожение уже полученной локальной копии. Личные чаты, презентации и исходные файлы не получают права автоматически; встроенные в карту материалы уже являются частью её содержимого.

Отдельно обработать: автор не вошёл, нет нужного тарифа, загрузка участников, нет сети, отключённая ссылка, недоступная карта, достигнут лимит, уже участник, отозванный доступ. У получателя действительного приглашения не требовать платную подписку только ради входа, если действующие правила допускают бесплатное участие.

## 4. Уточнения к изображениям

- На 04 иконка корзины у прекращения совместной работы не подходит: использовать символ отключения доступа; это не удаление карты.
- Фон под панелями сохраняет одну оболочку и вкладки, несмотря на различие 03/04.
- На 07 роль — информация о приглашении. Шеврон может объяснять права, но не менять их.
- Макеты используют вымышленные имена. Показ реальных имён/аватаров зависит от доступных данных; не заменять их случайными людьми и не раскрывать лишние контактные данные.
- Минимальная зона нажатия 44 pt, естественные переносы, поддержка Dynamic Type. Не уменьшать шрифт ради совпадения с PNG. Системные safe areas, VoiceOver и Reduce Motion обязательны.
- Цвета оболочки — из текущей темы; белая CTA и мятное выделение — предложенное оформление этого экрана. Не менять глобальные токены молча.

## 5. Проверка результата

1. Оба тарифа × оба периода: экран, выбранный StoreKit-продукт и платёж совпадают; trial корректен для разных eligibility.
2. Покупка/отмена/pending/ошибка/restore проверены через тестовую среду; платные права не включаются оптимистично.
3. Закрытие paywall возвращает к исходному вводу; возврат после входа/покупки не дублирует генерацию или приглашение.
4. Два тестовых пользователя: редактор действительно редактирует; наблюдатель не меняет карту ни через UI, ни через операции сервиса.
5. Действительная, отозванная и повторно открытая ссылки дают правильный результат. Отзыв ссылки не удаляет существующих участников.
6. Выход/удаление/прекращение общего доступа проверены с понятными последствиями; исходная карта владельца не исчезает.
7. Три размера iPhone, EN/RU, темы, крупный текст, VoiceOver, Reduce Motion и отсутствие сети. Footer paywall читается, выбранные варианты различимы не только цветом.
8. Пройти релевантные сборку и тесты; показать реальные скриншоты результата. Отдельно перечислить сценарии, которые не удалось проверить.

В этой итерации не реализуются сайт, новые схемы слайдов и отложенный переключатель презентаций. Не считать остальные разделы приложения завершёнными по завершению этого задания.
