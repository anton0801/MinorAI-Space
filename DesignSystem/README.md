# Minor Ai Design System

Переносимая копия дизайн-системы. Работает без интернета.

| Файл | Что это |
| --- | --- |
| `DESIGN.md` | Вся система одним документом: гайд, разделы, все токены, README компонентов, ассеты |
| `CODEX_PROMPT.md` | Готовая задача для Codex: экраны Mind Map и ассеты |
| `gallery.html` | Живые превью всех компонентов и экранов, с переключателем темы |
| `tokens.json` | Токены (источник) |
| `tokens.css` | Те же токены как CSS-переменные |
| `components/` | `bundle.css`, `bundle.js` и папка на каждый компонент: `preview.html` + `README.md` |
| `assets/` | Логотип, иконки, частицы paywall, скриншот главного экрана |

Онлайн-версия: https://claude.ai/artifact/1qTeqiiYd2HcTj3DsVEdsb
