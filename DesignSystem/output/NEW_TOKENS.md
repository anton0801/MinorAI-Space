# Токены

Новых визуальных токенов не добавлено. Все цвета, шрифты и радиусы интерфейса берутся из `../tokens.css`, готовые компоненты — из `../components/bundle.css`.

`--frame-width`, `--frame-height` и `--review-width` — параметры размера демонстрационного кадра, а не токены продукта. Размеры безопасных зон 59/34 взяты из задания. Координаты карты описывают раскладку данных, не новую шкалу отступов.

Серый `#959595` в SVG взят из раздела «Ассеты / Particles» исходного DESIGN.md; он используется только в экспортируемых ассетах. В интерфейсе ему не присваивается новая роль. SVG содержат явные значения цветов, поскольку они должны работать в Xcode без CSS.

В исходном bundle.css кольцо выделения и свечение корня реализованы через box-shadow. В выходных композициях кольцо заменено на outline, свечение — на размытый слой токена glow. Исходный bundle не изменён.
