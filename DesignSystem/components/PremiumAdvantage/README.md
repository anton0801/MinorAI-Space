# PremiumAdvantage

Шторка с подробным описанием преимуществ: цветная иконка и абзац на каждый пункт.

## Анатомия
`Sheet` с заголовком 18 Bold. Пункты: иконка 20 цвета `feature-*` + текст `subhead` 15 белым, интервал 10; между пунктами 40 (в превью сжато до 28).

## Правило
Цвета `feature-*` живут только здесь. Для карт используйте `feature-mindmap` (`map`).
