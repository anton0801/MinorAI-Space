# MapCanvas

Холст Mind Map: фон темы с точечной сеткой, масштаб и упрощённый вид при отдалении. **Новое.**

## Анатомия
- Фон `bg`, точки `canvas-dot` диаметром 2 (`map-dot`) с шагом 24 (`map-grid-pitch`).
- Индикатор масштаба: капсула 28, `surface` + `stroke`, `node-count` 12 Semibold с табличными цифрами. Появляется справа под верхней панелью во время масштабирования, прячется через 1.5 с.
- Ниже 50% (`zoom-lod`): сетки нет, листья — полоски 6 цвета ветки, плашки 1-го уровня без текста, если он меньше 8pt на экране.

## Поведение
Масштаб 25–300%, сдвиг одним пальцем по пустому месту, двойной тап — вписать карту. Подробно — в разделе «Mind Map: холст и узлы».
