# MessageBubble

Сообщение в чате: пользователь справа с мятной заливкой, ассистент слева на поверхности темы.

## Анатомия
- Радиус 16, отступы 14 × 10, текст `callout` 16 белым.
- Пользователь: `accent-tint` + обводка `accent-line`, выравнивание вправо.
- Ассистент: `surface` + `stroke`, выравнивание влево.
- С противоположной стороны свободно не меньше 40. Интервал между сообщениями 12.

## Mind Map (Новое)
Под ответом ассистента в чате по узлу — `Chip` «Add to Map». Ответы стоит рендерить с Markdown (списки, жирный).

## Не делать
Не используйте мятную заливку для чего-то, кроме сообщений пользователя.
