# CircleButton

Круглые иконки-кнопки: «+» с обводкой, закрытие шторки и иконки без фона.

## Варианты
- «+»: круг 32, обводка `stroke` 1px, `plus` 12 Bold. Сейчас заглушка; в новой версии открывает меню вложения (Photo, File).
- Закрыть: круг 30, `close-fill`, `xmark` 16 Bold.
- Иконка без фона: рамка 36, символ 18–20 белым (`house.fill`, `square.and.arrow.up`, `ellipsis`).
- Вход в режим Mind: PNG `mind-globe` 30.

## Правило
Видимая форма может быть меньше 44, зона нажатия — нет: добавляйте `.contentShape` и рамку 44.
