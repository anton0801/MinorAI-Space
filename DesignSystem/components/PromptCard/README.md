# PromptCard

Карточка «Ask me anything» внизу главного экрана: поле, кнопка «+», чип Media и отправка.

## Анатомия
- 361 × 120 на экране 393 (в коде жёстко 365), радиус 16, `surface` + `stroke` 1px.
- Поле `body-lg` 17, плейсхолдер `placeholder`, отступ слева ~18, сверху ~23.
- Внизу слева: `CircleButton` «+» 32 и `Chip` Media, интервал 10.
- Справа внизу: `SendButton` 34.

## Состояния
- Пусто: отправка неактивна.
- Есть текст: отправка активна; тап отправляет и открывает чат.
- Media активен: обводка чипа `accent`.

## Что передать
Текст, обработчики «+», Media, отправки.

## Не делать
Не растягивайте карточку по высоте под длинный текст выше 120 без анимации: поле в коде однострочное; многострочный ввод — отдельное решение.
