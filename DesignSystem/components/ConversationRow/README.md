# ConversationRow

Строка разговора в боковой панели: заголовок, дата, удаление.

## Анатомия
Радиус 12, `fill-row`, отступы 14 × 12. Заголовок `callout` 16 Medium в одну строку с многоточием, дата `caption` 12 `text-tertiary`, интервал 2. Справа `trash` 14 `text-tertiary` в рамке 30.

## Поведение
Тап открывает разговор и закрывает панель. Корзина удаляет сразу, без подтверждения; в новой версии лучше свайп влево с действием Delete.
