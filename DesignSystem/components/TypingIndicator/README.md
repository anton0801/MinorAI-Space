# TypingIndicator

Три точки в «пузыре» ассистента, пока AI готовит ответ.

## Анатомия
Точки 7 цвета `placeholder`, интервал 5, отступы 14 × 12, подложка как у ответа ассистента.

## Движение
Сейчас точки статичны. Предложение: пульсация прозрачности 0.35 → 1, 1.2 с на цикл, сдвиг фаз 0.15 с; при Reduce Motion — без пульса.
