# Connector

Связь между узлами: кривая Безье цвета ветки. **Новое.**

## Геометрия
От правой середины родителя к левой середине ребёнка; обе контрольные точки — посередине горизонтального зазора: `M x1 y1 C xm y1, xm y2, x2 y2`. Концы скруглены, стрелок нет.

## Толщина и цвет
- Корень → 1-й уровень: 2 (`connector-1`), цвет ветки 100%.
- Глубже: 1.5 (`connector-2`), `branch-*-line` (60%).
- Строится AI: пунктир 4 / 5 цвета `glow-solid` при 70%, пунктир бежит, 1 с на цикл.

## Движение
Новая связь рисуется от родителя к ребёнку (обрезка пути 0 → 1) за 0.3 с easeOut одновременно с появлением узла.
