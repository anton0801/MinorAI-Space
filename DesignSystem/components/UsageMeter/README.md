# UsageMeter

Счётчик бесплатных карт за месяц. **Новое.**

## Анатомия
Радиус 12, `fill-row`, отступ 14, интервал 8. Строка: «Free Maps» 13 слева и «2 of 3 this month» 13 Semibold с табличными цифрами справа. Полоса 4, фон `fill-thumb`, заполнение `accent`. Подсказка 12 `text-tertiary`: дата сброса и выгода Minor Plus.

## Где
Внизу «Your Maps» и вместо поля ввода на экране создания, когда лимит исчерпан. С подпиской не показывается.
