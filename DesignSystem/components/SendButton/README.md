# SendButton

Круглая белая кнопка отправки: главное действие любого поля ввода.

## Анатомия
Круг 34, `send-fill` (белый 90%), `arrow.up` 16 Bold цвета `on-send`.

## Состояния
- Готово: как выше.
- Неактивно: системное приглушение (~40%), когда поле пустое.
- Отправка: вместо стрелки системный `ProgressView` чёрного цвета.

## Правило
Белый круг на экране один. Он всегда означает «отправить / запустить».
