# TopBar

Верхняя панель главного экрана: кнопка боковой панели, пилюля Minor Plus и выбор модели.

## Анатомия
- Высота 44, сразу под статус-баром. Три колонки: левая и правая растягиваются, центр по содержимому.
- Слева: `menu` 25 (PNG), зона нажатия 44. Открывает боковую панель.
- Центр: `ProPill`.
- Справа: `ModelPicker`.

## Варианты
- Главный экран: все три элемента.
- Создание карты: без выбора модели (модель для карт выбирает сервер).
- Редактор карты использует свою панель: `house.fill`, название карты, `square.and.arrow.up` и `ellipsis` (см. `ScreenMapEditor`).

## Делать
- Держите поля 20–24 по бокам и выравнивание центра по оси экрана, а не по свободному месту.

## SwiftUI
Сейчас элементы стоят через `.position(x: UIScreen.main.bounds.width / 2 - 160, y: 40)`. В новом коде — `HStack` с `Spacer()` или `Grid`, чтобы панель не ломалась на других iPhone.
