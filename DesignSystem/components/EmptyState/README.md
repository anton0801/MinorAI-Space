# EmptyState

Пустое состояние списка: иконка, заголовок и подсказка по центру.

## Анатомия
Иконка 50 белым, заголовок `title-section` 18 Bold, подсказка `subhead-medium` 15 `text-secondary`, интервал 10, по центру свободного места.

## Тексты
- Разговоры (сейчас): «No conversations yet» / «Start one from the home screen.»
- Карты (Новое): «No Maps Yet» / «Tap the globe on the home screen to start one.», иконка `map`.
