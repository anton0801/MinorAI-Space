# Chip

Контурная капсула с иконкой и подписью: Media на главном экране и инструменты холста карты.

## Анатомия
- Отступы 12 × 6, радиус 15, обводка `stroke` 1px, без заливки.
- Иконка в рамке 20 + подпись `label` 14 белым, интервал 8.

## Состояния
- Обычный.
- Активный: обводка `accent`.

## Mind Map (Новое)
Ряд инструментов над полем редактора, когда ничего не выбрано: Node (`plus`), Layout (`tree`), Focus (`scope`), Export (`square.and.arrow.up`). Ряд прокручивается по горизонтали, если не помещается. При выборе узла ряд заменяется `NodeActionBar`.

Также чип источника в поле создания карты (иконка источника + домен + `xmark`) и чип «Add to Map» под ответом ассистента.
