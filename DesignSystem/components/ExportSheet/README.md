# ExportSheet

Шторка экспорта карты. **Новое.**

## Анатомия
`Sheet` «Export Map» и две группы `SettingsGroup`:
- FILE: Image (PNG), Document (PDF), Xmind, MindNode (OPML, PRO), Outline (Markdown).
- SHARE: Copy as Text, Share Link (PRO).

Справа в строке — формат 15 `text-chevron` или «PRO» 13 Semibold `pro`.

## Поведение
Файлы уходят в системное меню «Поделиться». Copy as Text — тост «Copied». PRO-строка без подписки открывает paywall на тарифе PRO.
