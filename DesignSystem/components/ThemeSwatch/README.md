# ThemeSwatch

Ряд кружков выбора темы в Settings → Chat themes.

## Анатомия
Плашка `row`, высота 80, радиус 10, отступы 20. Кружок 40 цвета `bg` своей темы, подпись `caption` 12, интервал 15. Выбранный — обводка белым 1px.

## Поведение
Ряд раскрывается под строкой Chat themes (пружина 0.5 / 0.7, задержка 0.1, из y −80). Смена темы — easeInOut 0.2, сохраняется в `UserDefaults` (`SelectedSphere`).
