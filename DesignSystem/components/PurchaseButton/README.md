# PurchaseButton

Кнопка оплаты подписки на paywall: зелёная плашка с ценой и бегущим бликом.

## Анатомия
361 × 60 (в коде 365), радиус 16, `premium`, цена `title-3` 20 Bold `on-premium`. Блик: полоса 50 с градиентом прозрачный → `sweep` → прозрачный, пробегает за 0.5 с раз в 4 с.

## Правило
`premium` и блик-покупка существуют только здесь. Для остальных главных действий — белый `send-fill`.

## Текст
Цена зависит от тарифа и периода: $9.99, $101.90, $24.99, $239.90.
