# Composer

Однострочное поле с кнопкой отправки высотой 60: композер чата, поле «Create miracles» и поле команд карты.

## Анатомия
- Высота 60 (`size-composer`), радиус 16, `surface` + `stroke` 1px, поля экрана 16, отступ снизу 12.
- Поле `body-lg` 17, слева 16; плейсхолдер `placeholder`.
- `SendButton` 34 справа, отступ 12.

## Варианты
- Чат: «Message».
- Режим Mind: «Create miracles» (сейчас) или «Map any topic or paste a link» (предложение).
- Редактор карты: «Ask or change this map». Отправка — команда AI для карты.
- С чипом источника слева (вставлена ссылка) или чипом узла над полем (чат по узлу).

## Состояния
Пусто → отправка неактивна. Отправка → вместо стрелки индикатор загрузки, поле очищено. Клавиатура → композер поднимается вместе с ней.
