# Minor AI — примеры виджетов

Пять визуальных концептов на экране iPhone, 13 октября 2026. Это изображения для обсуждения, не скриншоты работающего WidgetKit и не точные системные шаблоны. Размер, поля и размещение системных элементов проверяются на устройстве при реализации. Иконки других приложений и обои — контекст изображения, не поставляемые ассеты Minor.

## Предлагаемое поведение

«Сегодня» использует существующие задачи карты, без второй независимой базы. Различать отсутствие задач, отсутствие доступа к данным и завершение всех задач. Просроченные имеют текстовую пометку, не только цвет. Нельзя показывать положительный результат изменения, если команда завершения потерялась. В текущем коде TickTaskIntent пишет отложенную команду, а WidgetBridge применяет её при открытии приложения — этот сценарий требует проверки отдельно от дизайна.

Маленький виджет — обзор с одним переходом. Средний — отдельные действия для checkbox и текста. Проектный виджет в этом наборе показывает именно выбранную карту; выбор проекта доступен в настройке виджета. Слайды могут стать дополнительным вариантом позже; не считать их уже спроектированными этим PNG. При утрате доступа/удалении проекта — «Выберите проект», а не старая приватная миниатюра.

«Записать мысль» не обещает запись звука внутри виджета. Он открывает нужный режим, после чего пользователь начинает ввод/запись и даёт необходимые разрешения. Не запускать микрофон скрытно и не создавать пустую карту от одного касания ярлыка. Если подписка ограничивает голосовой источник, сохранить действующие правила: вход в режим не означает бесплатную генерацию. Диктовка в чате и платный источник для карты — разные сценарии.

Для блокировки — монохромная адаптация и минимум текста. Предусмотреть режим скрытия названий: «3 задачи» вместо содержимого. Решение об объёме отображаемого текста должно быть явным и согласованным с системной приватностью. Круглый вариант показывает количество предстоящих/просроченных задач согласно единому определению с Today; подпись не должна обещать только сегодняшние, если туда включено просроченное.

## Перед реализацией

- Сегодня уже существует в MinorWidgets/MinorWidgets.swift для small/medium/accessoryRectangular/accessoryCircular; обновлять его, не дублировать.
- Capture и Continue — предложенные новые виджеты, не существующая готовая функциональность.
- Проверить актуальность данных без запуска приложения, смену дня и часового пояса, длинные RU/EN-названия, отсутствие сети, смену аккаунта/прав и системное тонирование. Не рассчитывать на непрерывное обновление или анимацию.
- Не копировать искусственные часы/иконки/обои из концептов в приложение. Использовать нативные контейнеры, системные размеры, доступные действия и настоящий логотип, если он добавляется.
- Системные режимы оформления важнее жёстко заданного мятного цвета: содержание должно оставаться понятным без него.

Изображения созданы встроенным image_gen. Запросы и происхождение — prompts.json. Код приложения и виджетов при создании этих примеров не изменялся.
