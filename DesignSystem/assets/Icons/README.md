# Icons

Собственные PNG-иконки проекта. Все в одну белую краску на прозрачном фоне; цвет задан в файле, поэтому на светлом они не работают. Остальные иконки интерфейса — SF Symbols (список в README системы).

- `menu.png` — три полосы, кнопка боковой панели в верхней панели, 25.
- `mind-globe.png` — глобус, вход в режим Mind (создание карты) под карточкой ввода, 30.
- `home.png`, `message.png`, `photo.png`, `settings.png` — есть в ассетах, в текущих экранах вместо них используются SF Symbols `house.fill`, `message`, `photo`, `gear`.
