# Logos

- `minor-mark.png` — знак Minor: семиугольник из трёх концентрических колец с заполненным центром. Одна краска, белая (#FFFFFF), на прозрачном фоне, 700 × 700. В приложении: 28 в пилюле Minor Plus, 110 водяным знаком при 0.2, 150 на paywall, 110 на экране генерации. Только на тёмном фоне; не перекрашивать, не обводить, не поворачивать (кроме анимации появления на paywall).
- `minor-mark@3x.png` — тот же знак, 2100 × 2100, для иконки приложения и крупных изображений.
