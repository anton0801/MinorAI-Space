# Minor AI — единый пакет для Claude Code

Собрано 12 октября 2026. Это материалы для доработки существующего iOS-проекта: решения, дизайн, UX-сценарии, аудит и ранее подготовленные маркетинговые материалы. Новые детали UX дополняют основное задание, прежняя отсрочка переключателя презентаций сохраняется. ## Отложено — не делать сейчас

Последнее прямое решение пользователя: идею сохранённых презентаций внутри карты оставить на потом. Это включает автоматическое открытие прежней презентации вместо создания, переключатель «Для команды / Для клиента», запоминание выбранного варианта и отдельное действие «Создать ещё» в этом переключателе.

Для будущего сохранены весь набор [slides-versions](DesignSystem/concepts/2026-10-12/slides-versions/README.md) и экран `project-continuity/02-slides-switcher.png`. На обзорных листах они также присутствуют. Не реализовывать их по изображению вопреки этому решению.

Сейчас действие «Слайды» из карты сохраняет вход в создание с явным запуском генерации. Уже созданные документы открываются через библиотеку. Сохранение документов, редактирование, экспорт и защита ручных правок остаются обязательными. Общая связка карты и чата не отменяется.

Другие ранние альтернативы — Space-dashboard, Paper, onboarding-first-map и первоначальная Focus-главная — только для сравнения. Канбан, таймлайн, автоматические правила меток и другие идеи из раздела будущих итераций аудита не обязательны сейчас.

## Что довести при реализации

- Не терять доступ к существующим функциям карт: задачи, сроки, заметки, ссылки, изображения, связи, рамки, поиск, фокус, история, совместная работа, учёба, показ и экспорт.
- Объединить редактирование встроенных полей слайда и свободных элементов. Смена макета не теряет текст и не придумывает числа. Стиль и экспорт должны поддерживать одни и те же данные.
- Чат проекта должен сохранять историю и черновик; личный разговор не публикуется участникам карты автоматически. Предложения ИИ применяются явно, с отменой и проверкой актуальности документа.
- Сохранить материалы и происхождение утверждений; не выдумывать страницы, цитаты или таймкоды. Примеры в макетах демонстрационные.
- Довести ошибки, отсутствие сети/доступа, лимиты, отмену, синхронизацию и достоверные состояния сохранения. Не показывать рабочие контролы над отсутствующей моделью.
- Проверить русский/английский, существующие темы, три размера iPhone, клавиатуру, Dynamic Type, VoiceOver и Reduce Motion. Для проверки использовать отдельный тестовый симулятор, не вошедший в настоящий аккаунт.

Подробные критерии — в основном задании; UX источников, импорта, памяти и задач — в README project-continuity. Эти разделы составляют задание вместе, а не заменяют друг друга.

## Границы пакета

Включены оригиналы концептов, обзорные листы, запросы к генератору и манифесты. Служебные файлы macOS, кэш, старые вложенные ZIP и дубли распакованных пакетов исключены. Пробные скриншоты в `rejected` и старые кадры в `revisions` — архивные материалы, не финалы. Локальные абсолютные пути в старых промптах — происхождение референсов; для работы использовать соответствующие файлы внутри пакета или актуального репозитория.

Для просмотра HTML можно запустить локальный HTTP-сервер из корня распакованного пакета и открыть `DesignSystem/output/index.html`, `shots/index.html` или `website/index.html`. Это не требует публикации.

Статичные макеты не являются интерактивным прототипом. Сборку и экспорт нового интерфейса предстоит проверить при реализации. В отчёте Claude Code нужны реальные изменения, пройденные проверки и оставшиеся ограничения, а не отметка готовности по наличию PNG.
