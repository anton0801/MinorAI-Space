# Minor AI 3.0.1 · Custom Product Pages · EN-US

Финальные материалы собраны 16 октября 2026. Все экраны показывают интерфейс 3.0.1 с наполненными примерами: поездка в Японию, фотосинтез, кулинарный подкаст. Прежняя визуальная концепция сохранена: крупные заголовки, спокойные цвета, настоящий интерфейс внутри рамки.

## Тестирование

A: “Think it. Map it.” B: “Mind maps. Made with AI.” Остальные семь кадров совпадают побайтно. Тест проверяет заголовок; это отдельный эксперимент от вариантов оформления в соседней папке `shots/appstore-en-3.0.1`. Не смешивать обе гипотезы в одном сравнении.

Для основной страницы доступен Product Page Optimization. CPP разделяют поисковые намерения; прямое сравнение разных CPP не является рандомизированным A/B-тестом. План, метрики и ограничения описаны в стратегии. Страницы не опубликованы, тесты и реклама не запущены.

Ключи — гипотезы, без данных о частотности. CPP выбирает слова из последней одобренной версии; предложенный новый список не применён к метаданным приложения. Перед загрузкой сверить доступные слова в Connect.

## Исходники и воспроизведение

Съёмка 15 октября 2026; успешная сборка сохранена в `logs/build-final.log`. База кода `681b515` плюс локальные DEBUG-сценарии. Снимки `map` и `task` использованы из более поздней съёмки 3.0.1 в соседней папке `shots/appstore-en-3.0.1/raw`; остальные — из съёмки этой задачи. UI не перерисован; цвета внутри приложения зависят от выбранной темы. Демо-контент не является личными данными или ответом сервера в реальном времени.

Для повторного экспорта с сохранёнными исходниками:

```sh
python3 preview.py
python3 render_previews.py --all
python3 qa_layouts.py
python3 package.py
```

Скрипты запускаются из этой папки; Chromium указан в `render_previews.py`, для QA нужен Pillow. Для новой съёмки — отдельный симулятор и `capture.py --device UUID`. Для карты поездки использовать более поздние флаги из `../appstore-en-3.0.1/scenes.txt`; для задачи выставить будущую дату и разрешить напоминания перед съёмкой. Не использовать общий идентификатор `booted`.

Оба созданных ранее симулятора отсутствуют в системе при финальной проверке 16 октября. В финальной сессии новые не создавались. Старые дизайн-превью перемещены в `archive/previous-ui-drafts` и исключены из ZIP.
