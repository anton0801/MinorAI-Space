# Minor AI — скриншоты App Store

Готово: 8 английских и 8 русских кадров из настоящего Debug-приложения, снятых 4 октября 2026 года. Все файлы: 1320 × 2868 px, RGB PNG, без альфа-канала. Оформление: тёмный фон #121212, лёгкое свечение #2FFF9E, подписи 90–96 px, реальный экран уменьшен до 80% без обрезки содержимого.

## Где файлы

- `app-store/en/`, `app-store/ru/` — оформленные изображения для загрузки, в порядке 01–08.
- `Minor-AI-App-Store-EN-RU.zip` — оба готовых набора и обзорные листы. Распакуйте перед загрузкой.
- `raw/en/`, `raw/ru/` — исходные экраны, также без альфа-канала.
- `index.html` — локальная галерея; `contact-sheet-en.jpg`, `contact-sheet-ru.jpg` — быстрый обзор (не загружать в App Store).
- `manifest.json` — подписи, флаги запуска и SHA-256; `qa.json` — результаты проверки; `ocr-raw.json` — распознанный текст.
- `rejected/` — пробные кадры, НЕ для загрузки.

## Порядок

1. Карта с тарифами $12.99 и $24.99.
2. Источники для создания карты.
3. Помощник работает с картой.
4. Дизайн презентации.
5. Задачи и напоминания.
6. Карточки и тесты.
7. Приглашение к совместной работе.
8. Презентация и заметки докладчика.

Кадр 8 заменён разрешённым вариантом `-demoPresentDeck`: голосовой экран на чистом симуляторе показывает запрос разрешить обработку данных ИИ. Подпись заменена на “Your slides and speaker notes, together” / «Слайды и заметки для выступления». В текущем приложении этот флаг открывает редактор презентации, поэтому изображение и подпись показывают именно его. Список карт проверен как альтернатива, но с одной демо-картой он оказался менее содержательным.

Для кадра 7 добавлен `-demoFit`, чтобы карта под панелью приглашения помещалась по ширине. Частично видимые крайние элементы горизонтальных лент — штатная прокрутка приложения; основные подписи и кнопки проверены визуально.

Обе Debug-сборки завершились успешно (`build.log`, `build-final.log`). Код Release не изменён этой задачей. Остальные ранее существовавшие изменения проекта сохранены.

## Повторная съёмка

После съёмки отдельный симулятор выключен, финальная Debug-сборка установлена. Для повторения из корня проекта:

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcrun simctl boot 89F72117-04E2-4B4D-A1F4-8A669E1AEC8A
xcrun simctl bootstatus 89F72117-04E2-4B4D-A1F4-8A669E1AEC8A -b
python3 shots/scripts/capture.py --language en
python3 shots/scripts/capture.py --language ru
python3 shots/scripts/compose.py
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swiftc shots/scripts/ocr.swift -o /tmp/minor-shots-ocr
/tmp/minor-shots-ocr "$PWD/shots/raw" "$PWD/shots/ocr-raw.json"
python3 shots/scripts/package.py
```

Скрипты Python используют Pillow. Доступ к CoreSimulator и Apple Vision может требовать запуска вне ограниченной песочницы. `capture.py` всегда обращается к конкретному UUID, не к `booted`. Демо-даты относительные, поэтому последующая съёмка может показать другую дату; порядок учебных карточек задаёт приложение.

## Загрузка

В App Store Connect откройте Minor AI → версия 2.0 → Previews and Screenshots → iPhone 6.9" Display. Для English загрузите восемь PNG из `app-store/en`, для Russian — из `app-store/ru`, в порядке 01–08. Этот набор подготовлен локально; в App Store Connect ничего не загружено.
