# Minor AI — «Придай мыслям форму»

Пробный вертикальный проморолик, 10 секунд, 1080 × 1920, 60 fps.

## Готовые материалы

- `Minor-AI-Promo-10s.mp4` — финальный H.264/AAC с музыкой и звуковыми эффектами.
- `soundtrack.wav` — отдельный стереомикс, 48 kHz / 24-bit.
- `storyboard.jpg` — обзор восьми кадров.
- `poster.jpg` — обложка.

## Сценарий

| Время | Сцена |
| --- | --- |
| 0.00–1.78 | Карточки документа, видео, голоса и идеи сходятся в одну точку. |
| 1.78–4.10 | Настоящий экран интеллект-карты на телефоне, подписи о связях и структуре. |
| 4.10–7.00 | Экран редактора, реальный слайд выходит из телефона и раскрывается в стопку. |
| 7.00–10.00 | Оригинальный белый знак, Minor AI, слоган и адрес сайта. |

Исходники интерфейса: `shots/raw/ru/01-map.png`, `shots/raw/ru/08-present.png`.
Знак: `DesignSystem/assets/Logos/minor-mark@3x.png`.
Копирайтинг, композиция, программная анимация и инструментальная подложка созданы для этого ролика.

## Звук

Три эффекта (`assets/sweep.mp3`, `assets/nodes.mp3`, `assets/logo.mp3`) созданы через ElevenLabs Sound Effects API. Запрос отдельной музыки через Music API вернул HTTP 402 `paid_plan_required`; вместо него использована оригинальная локально синтезированная инструментальная подложка. Все эффекты синхронизированы с монтажом; целевой уровень микса — −16 LUFS. Измерение финального AAC: −16.8 LUFS, true peak −1.4 dBTP, без клиппинга.

`audio-cues.json` хранит тайминг; `assets/audio-prompts.json` — запросы генерации без ключа. Ключ не сохранялся в файлах проекта.

## Повторный рендер

Нужны Python с Pillow и NumPy, FFmpeg, системные шрифты Arial (пути macOS указаны в `render.py`).

```sh
python3 promo/render.py
python3 promo/mix_audio.py
ffmpeg -y -i promo/silent-master.mp4 -i promo/soundtrack.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 256k -t 10 -movflags +faststart promo/Minor-AI-Promo-10s.mp4
```

Генерацию ElevenLabs повторять не нужно: готовые эффекты сохранены локально. Для намеренной повторной генерации: `python3 promo/generate_audio.py` (ключ вводится скрыто).
