# Редизайн Minor AI — план и ход работ

Источник требований: `Minor-AI-Claude-Code-Handoff-2026-10-12.zip` (HANDOFF_START_HERE.md, DesignSystem/CLAUDE_CODE_PRODUCT_COMPLETION.md, DESIGN_COMPLETENESS_AUDIT.md, concepts/2026-10-12). Отложено самим заданием: автооткрытие сохранённых презентаций из карты, переключатель презентаций, «Создать ещё».

Решения пользователя: бесплатным сверху «Получить Plus», подписчикам «Minor AI». Серверные функции выкладываются, если не задевают пользователей старой версии (закрытие моделей чата — только для новых клиентов по заголовку).

Проверка: только симулятор iPhone 16 `EA8D289A…`, запуск с `-auditSignedOut`. Другие размеры — временные симуляторы, удалить после проверки.
